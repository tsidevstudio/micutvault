# Getting Started with MicutVault

MicutVault is a privacy-focused Android vault for photos, videos, audio and private notes.

MicutVault is publicly available on Google Play.

## Install MicutVault

Install the official version from Google Play:

https://play.google.com/store/apps/details?id=com.tsi.micutvault

Official product page:

https://tsidevstudio.com/apps/micutvault

## First setup

On first launch:

1. Create a Primary PIN between 6 and 12 digits.
2. Confirm the PIN.
3. Configure optional recovery and biometric access if desired.
4. Complete setup and enter the private vault.

Keep your Primary PIN safe.

## Private content

MicutVault currently supports:

- Photos
- Videos
- Audio
- Private notes

Private content is designed to remain protected inside the local vault.

## Access protection

MicutVault includes:

- Primary PIN access
- Optional biometric unlock
- Configurable inactivity auto-lock
- Configurable lockout after repeated failed PIN attempts
- Optional intruder detection

Availability of biometric features depends on the Android device and its supported secure authentication methods.

## 9 disguise modes

MicutVault can appear using one of nine disguise modes:

- Calculator
- Notes
- Books
- Files
- Calendar
- Clock
- Tasks
- Scanner
- Recorder

Calculator mode functions as a normal calculator while also supporting private PIN access to MicutVault.

## Recovery and deleted content

MicutVault includes:

- 30-day encrypted Trash
- Encrypted backup
- Restore support

These features are designed to help protect against accidental loss while keeping the vault local-first.

## Privacy

The current MicutVault release has:

- No account requirement
- No ads
- No analytics
- No mandatory cloud
- No subscription
