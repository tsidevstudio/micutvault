# Getting Started with MicutVault

MicutVault is a lightweight private-media vault for Android.

## Public features

Depending on the current version and testing stage, MicutVault may include:

- PIN-protected access
- Supported biometric access
- Disguise options
- Intruder-photo functionality where enabled
- Local-first private-media storage

## Testing

MicutVault may be distributed through testing channels before broader release.

Public availability can therefore change over time.
