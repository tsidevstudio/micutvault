# MicutVault Troubleshooting

## I cannot unlock the vault

- Confirm you are using the intended PIN
- Confirm biometric access is still available if enabled
- Restart the app after Android security changes
- Contact support before taking destructive actions

## A disguise option does not appear as expected

Behavior can vary by Android version and current testing build.

## Intruder photo does not work

Confirm required permissions are granted and that the feature is enabled in the current build.
