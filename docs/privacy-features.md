# MicutVault Privacy Features

This page describes user-visible privacy features only.

## Local-first approach

MicutVault is designed around local control and a focused vault experience.

## PIN and biometrics

PIN access and supported biometric access may be available depending on version and device support.

## Disguise options

MicutVault can present supported disguise experiences intended to make the app less obvious in everyday use.

Internal implementation details are intentionally not documented publicly.

## Intruder photo

Where enabled, MicutVault may provide intruder-photo functionality.

Behavior can depend on Android permissions and device support.

## Publication boundary

This repository does not publish authentication internals, security-sensitive storage layouts, disguise implementation logic or source code.
