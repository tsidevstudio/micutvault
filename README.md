# MicutVault

**Private Media Vault for Android**

MicutVault is a privacy-focused Android vault developed by **TSI Dev Studio**.

The app is now publicly available on **Google Play**.

## What it does

- Private storage for photos
- Private storage for videos
- Private audio storage
- Private notes
- Primary PIN-protected access
- Optional biometric unlock
- 9 disguise modes:
  - Calculator
  - Notes
  - Books
  - Files
  - Calendar
  - Clock
  - Tasks
  - Scanner
  - Recorder
- Optional intruder detection
- Configurable lockout protection
- Inactivity auto-lock
- 30-day encrypted Trash
- Encrypted backup and restore
- Photo sorting, zoom and slideshow
- Local-first privacy model

## Current release

MicutVault completed Google Play closed testing and became publicly available in Production on **November 4, 2026**.

The current Production release is fully available for free.

A future update is planned to introduce a **Free + Lifetime** model with a one-time purchase.

No subscription is planned.

## Privacy principles

- Local-first design
- No account required
- No ads
- No analytics
- No mandatory cloud storage
- No subscription
- Minimal public disclosure of security-sensitive implementation details

## About this repository

This repository contains public product information, documentation, verification links and release-related resources for MicutVault.

Unless explicitly stated otherwise, the MicutVault application source code is not published in this repository.

MicutVault is a privacy product. Public documentation is intentionally limited to user-visible behavior, product information and responsible security reporting.

Implementation details that could weaken security or make protective mechanisms easier to reproduce or bypass are intentionally not documented publicly.
